3SDS v3.0

Not one look.
A method.

3Shamrocks Studio doesn't stamp a house style on every product. We author a brand — then the entire UI regenerates from it. That's the IP.

Four layers.
One contract.

Only Layer 1 changes per product. Everything else is identical code — different output because the knobs feed different values. That's why SHOMER doesn't look like Trashure, and neither looks like this studio site, and they still feel like one house.

L0Primitives. Spacing ramp, type sizes, breakpoints, elevation, motion curves. Shared craftsmanship.
L1Brand knobs. Hue ramp, signature color, type pairing, radius personality, duration scale. One CSS block.
L2Semantics. --bg, --text, --accent, --border — computed for light and dark. Code talks in meaning, not hex.
L3Components. Buttons, cards, fields, badges. They consume tokens. They never hard-code a look.

Space Grotesk × Inter becomes Sora, Baloo 2, Quicksand, Oswald, Heebo — whatever Layer 1 says.

Studio palette — locked

This website uses the 3S house brand. Cosmic indigo #5f4fcc as primary. Shamrock #52cc7a / #7cfc90 / #18895b as the living heart. Navy #2d3f54 as the ink. Cream #e8e7ea as the paper. Space Grotesk for display. Inter for body. The logo is never boxed, never recoloured, never faked.

Client brands — never reinvented

AposHealth and Vibrant Gastro keep their real logos, screens, and colors. We present them better. We do not restyle them into shamrocks. That's the difference between a studio and a template.
