Advanced
Advanced Capability

Agents that work together.

Beyond single-model nodes — J8N.IX lets you orchestrate multi-agent pipelines where specialist AI agents collaborate, pass context, and hand off tasks like a well-run team.

01

Orchestrator Agent

Receives the task, breaks it down, delegates to specialist agents with full context.

02

Context Passing

Each agent receives the full output of its predecessor. No prompt re-engineering. No data loss.

03

Parallel Execution

Agents run in parallel where possible. Classification + summarization at the same time.

04

Human-in-the-Loop

Pause any agent pipeline for human review. Approve, reject, or edit before continuing.

API-First

Every workflow is
an API endpoint.

Build a workflow in the visual editor, then expose it as a REST endpoint. Trigger it from your product, your cron job, your mobile app, or anywhere HTTP lives.

🔑

API Keys + OAuth

Token-scoped access, per-workflow keys, audit logs on every call.

⚡

Async + Sync Execution

Synchronous for fast workflows, async with webhook callback for long-running agents.

SDK Coming

TypeScript and Python SDKs in preview. Import, trigger, and monitor from your codebase.

OpenAPI Spec

# Trigger a workflow via API
$ curl -X POST \
  https://api.j8n.ix/v1/workflows/support-triage/run \
  -H "Authorization: Bearer j8n_sk_..." \
  -H "Content-Type: application/json" \
  -d '{
    "trigger": {
      "type": "email",
      "from": "user@example.com",
      "subject": "Billing issue with my account",
      "body": "..."
    }
  }'
