3SDS · the studio IP

Not one look.
A method.

We don't force a studio skin onto every product. We build a distinct brand — then generate the UI, the layout, and the site from that brand. Shared craft underneath. Different worlds on top.

L0Primitives — spacing, type scale, motion. Same for every product.
L1Brand knobs — hue, type, corners, feel. One block. The whole world changes.
L2Semantic color — meaning, not hex. Light and dark, computed.
L3Components — buttons, cards, forms. Identical code. Different output.
